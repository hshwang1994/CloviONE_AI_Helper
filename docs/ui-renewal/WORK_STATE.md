「사용자 매핑」 단계, 외부 연동의 「Notion」 유형이 그대로 있었다. 공통점은 하나다 — **거기서
할 수 있는 일이 없다.** 화면·라우트·라우터·응답 칸을 내리고, 표(`user_notion_mappings`)와
감사 대상 유형과 이름표는 남겼다: 옛 기록을 걸러 볼 방법이 사라지면 안 된다(S11 이
`runner`·`workflow` 에 쓴 규칙 그대로).

🔴 **그 잔재 뒤에 조용한 제품 결함 셋이 있었다**(D-317 · D-318). 셋 다 오류를 안 냈다.

* **오프보딩 후임 후보**가 `user_notion_mappings` 를 INNER JOIN 해서 **컷오버 이후에 만든
  계정이 명단에서 통째로 빠졌다.** 재배정 경로는 앱 user_id 를 그대로 받으므로 막을 이유도
  없었고, 화면은 이유를 말하지 않고 그냥 안 보여 줬다
* **조직 정합성 진단**이 옛 id 만 «아는 값» 으로 세서 새 계정이 담당한 **정상 티켓**을 매번
  「연결 실패」로 올렸다 — 그리고 안내는 이제 없는 화면으로 가라고 말했다. 진단이 없는
  문제를 만들어 내고 있었다
* **초기 설정 체크리스트의 「사용자 매핑」 단계는 새 설치에서 영원히 안 끝난다**(그 연결을
