## NOW
**S22 가 물은 것은 하나다 — 지금 그린 화면이 Release 할 수 있는 상태인가.** 그래서 판정은

🔴 **시각 결함 다섯을 뿌리에서 고쳤다.** 전량 캡처가 승격 검사 넷을 115페이지에서 빨갛게
만들었고, 원인은 다섯이었다.

- **개수 열 둘이 어휘를 안 썼다**(D-331) — 부서·직책의 인원 열이 좌정렬·비고정이라 세로로
  비교할 수 없었다. `type: "count"` 하나가 그 셋을 준다.
- **한 줄의 조작기가 두 높이로 섰다**(D-332) — 표 머리글의 정렬 단추와 필터 단추가 6px,
  그리고 **px 리터럴이 4K 레버를 안 타서** 반응 칩·조건 칩·글자 단추가 3840 에서만 갈렸다.
  좁은 화면에서는 우연히 같아 아무도 못 봤다. 높이는 이제 전부 `CONTROL` 토큰에서 나온다.
- **바닥을 맞추는 값이 폭까지 반씩 나눴다**(D-333) — 「내 프로필」 두 줄이 요구 폭 2.88배
  차이인데 트랙은 794px 로 같았다. 줄마다 어느 쪽이 폭을 요구하는지를 적는다.
- **자리가 없는 화면을 「회색이다」로 셌다**(D-334) — 좁은 폭의 로그인은 히어로가 숨어
  Brand 면이 없는데 프로브가 정렬용 `<header>` 를 집었다. 화면이 `data-brand-role="none"`
  으로 그 사실을 말한다. 반대편 하나는 **제품을 고쳤다**: 「내 활동」의 종류 토글이 MUI
  기본 회색 면으로 선택을 말하고 있었다(이 제품은 잉크와 레일로 말한다 — D-289).
- **프로브 문턱 둘이 절벽이었다**(D-329 · D-330) — P-40 과 P-43 이다.
