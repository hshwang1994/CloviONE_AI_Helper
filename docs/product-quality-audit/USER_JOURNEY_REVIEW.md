# 일반 사용자 여정 검수 (USER_JOURNEY_REVIEW)

라이브 서비스에 실제 요청을 보내 확인한 결과다. 코드 추적이 아니라 실행 결과다.
요청자는 실제 계정(hshwang@goodmit.co.kr)이고, 데이터는 실제 Notion 업무 데이터(프로젝트 22건, 티켓 218건)다.

## 수정 전에 무엇이 망가져 있었나

같은 뿌리에서 나온 결함이다. 낱말을 문장 어디서든 부분일치시켜 조건으로 삼았다.
그래서 사용자가 말하지 않은 조건이 조용히 붙었고, 결과는 0건이거나 정반대 데이터였다.
0건에는 오류 표시가 없다. 사용자는 "데이터가 없구나"라고 믿는다. 이것이 이 결함군이 위험한 이유다.
