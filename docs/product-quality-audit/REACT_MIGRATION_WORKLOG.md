## 기술 구조 (확정)
- Vite + React 18, `frontend/`. 빌드 산출물 `app/static/react/`(기존 정적 서빙에 합류, 커밋해서 배포).
- **CSP 필수 설정**(app/core/middleware.py가 `script-src/style-src 'self'` 강제):
  vite.config.js에 `assetsInlineLimit:0`, `modulePreload.polyfill:false`, `cssCodeSplit:false`.
  인라인 스크립트/스타일·CSS-in-JS 금지 → 외부 해시 자산만. 매 빌드 후 index.html에 인라인 0 확인.
- 라우팅: `react-router-dom` HashRouter(기존 `#section` 스킴과 호환, 서버 rewrite 불필요).
- 서버상태: `@tanstack/react-query`. API 클라이언트 `src/lib/api.js`(same-origin 쿠키+CSRF, 401 처리).
- 인증: `src/app/auth.jsx` AuthProvider(/api/me → user+csrf).
- 디자인 시스템: `src/ui/kit.jsx`+`kit.css`(Card/Badge/Button/StatCard/Callout/EmptyState/ErrorState/
  Skeleton/PageHeader), 토큰은 `src/styles/tokens.css`(브랜드 원본 재사용). 셸 `src/app/App.jsx`.

## 컷오버 보류 사유(중요·안전)
`/admin`을 React로 바꾸려면 **기능 동등성**이 필요한데(지시서 §24), 현재 React는 읽기+생성+
lifecycle까지고 **편집(수정) 폼이 대부분 미구현**이다. 지금 컷오버하면 실사용자가 편집 기능을
잃는 **기능 후퇴**가 된다. 그래서 컷오버 전 편집 폼 파리티가 선행돼야 한다. 현재는 /static/react/
공존(바닐라 /admin 풀기능 유지)이 안전한 상태.
