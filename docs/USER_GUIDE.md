# USER GUIDE — 업무 도우미 사용 안내

ClovirONE 업무 도우미는 사내 웹 채팅으로 티켓·프로젝트를 조회/생성하는 서비스입니다.
접속 주소: `https://clovirone-ai.gooddi.lab` (사내망 전용).

> 사내 self-signed 인증서를 사용하므로 브라우저가 보안 경고를 표시할 수 있습니다.
> 안내에 따라 예외를 승인하고 진행하세요.

## 로그인

1. 관리자에게 받은 **회사 이메일**과 **임시 비밀번호**로 로그인합니다.
2. 이메일/비밀번호가 틀리면 어떤 쪽이 틀렸는지 알려주지 않습니다(보안 정책).
3. **5회 연속 실패 시 계정이 15분간 잠깁니다.** 즉시 해제가 필요하면 관리자에게 요청하세요.

## 첫 로그인 — 비밀번호 변경 필수

임시 비밀번호로 로그인하면 비밀번호 변경 화면으로 이동하며, 변경 전에는 다른 기능을
사용할 수 없습니다. 새 비밀번호 규칙:

- **최소 12자**
- 대문자 / 소문자 / 숫자 / 특수문자 중 **3종 이상 조합**
- 기존 비밀번호와 달라야 함

변경하면 다른 기기의 로그인이 모두 해제됩니다(본인 보호 목적).

## 채팅 사용법

- 왼쪽 사이드바 **"+ 새 대화"**로 대화를 시작합니다. 첫 메시지가 대화 제목이 됩니다.
- 입력창에 자연어로 요청하고 **Enter**로 전송합니다(**Shift+Enter**는 줄바꿈).
  메시지는 최대 5,000자입니다.
- 전송하면 "처리 중" 상태가 표시되고, 도우미 응답이 도착하면 자동으로 나타납니다.
  Notion 조회·생성처럼 실제 데이터를 다루는 요청은 수십 초가 걸릴 수 있고, 화면은 최대
  10분까지 기다립니다. 그 안에 끝나지 않으면 실패 안내와 함께 "다시 시도"를 안내합니다.
- 같은 메시지를 실수로 두 번 보내도(더블클릭/새로고침) 한 번만 처리됩니다.
- 대화는 사이드바에서 이름 변경(✎)·삭제(🗑)할 수 있습니다. 목록·선택 버튼(원탭)과 티켓 카드의
  "상세"·"Notion에서 열기"도 그 자리에서 바로 쓸 수 있습니다.

## 빠른 실행 버튼 (Quick Prompts)

새 대화 화면 하단의 버튼을 누르면 해당 문구가 입력창에 채워집니다:

- 내 할당 티켓 보기 / 이번 주 마감 티켓 / 내 담당 프로젝트 / 새 티켓 만들기 / 도움말

## 티켓·프로젝트 조회

"내 티켓", "내 프로젝트"처럼 **본인 기준**으로 물으면 로그인 계정의 이메일로 본인을
자동 식별합니다 — 이름이나 이메일을 입력할 필요가 없습니다.

> 계정이 아직 Notion 사용자와 연결되지 않았다면 본인 기준 조회 대신 연결이 필요하다는
> 안내가 표시됩니다. 이 경우 관리자에게 **Notion 매핑**을 요청하세요.
> 특정 조건 조회(예: "진행 중인 전체 티켓")는 매핑 없이도 동작합니다.

## 요청이 실패했을 때 — 다시 시도

연동 서비스 순단 등으로 처리가 실패하면 메시지에 실패 표시와 **"다시 시도"** 버튼이
나타납니다. 버튼을 누르면 같은 내용이 다시 처리됩니다. 반복 실패하면 잠시 후
재시도하거나 관리자에게 문의하세요.

시스템 점검 중에는 새 요청이 차단되고 점검 안내 메시지가 표시됩니다.

## 알림

요청 처리 실패, 계정 잠금 등 중요한 이벤트는 계정별 인앱 알림으로 기록됩니다
(본인 것만 조회 가능). 채팅 화면에서는 실패한 메시지에 실패 표시와 "다시 시도"
버튼이 바로 나타나므로 별도 알림 확인 없이 대응할 수 있습니다.
(현재 이메일/Teams 발송은 제공되지 않습니다 — 인앱 전용)

## 내 정보 / 세션

- 화면 오른쪽 위 **상단바의 아바타/이름**을 누르면 사용자 메뉴가 열립니다. 인사말과 이름·역할이
  상단바에 함께 표시됩니다.
- **비밀번호 변경**: 상단바 사용자 메뉴 → 비밀번호 변경 (현재 비밀번호 확인 후 변경)
- **로그아웃**: 상단바 사용자 메뉴 → 로그아웃
- 사용자 메뉴에서 화면 테마(밝게/어둡게)도 전환할 수 있습니다. (관리자는 채팅↔관리자 콘솔 전환도
  이 메뉴에서 합니다.)
- 30분간 활동이 없거나 로그인 후 8시간이 지나면 자동 로그아웃됩니다.

별도의 '프로필' 화면은 없습니다 — 부서·직함 등은 관리자가 관리자 콘솔에서 설정합니다.

## 이미지 첨부 (스크린샷 분석)

채팅에 이미지를 올려 에러 화면·표·차트를 분석하거나 티켓에 반영할 수 있습니다.

- **첨부 방법**: 입력창 왼쪽 **📎 버튼** 또는 캡처 후 **Ctrl+V 붙여넣기** (PNG/JPEG/WebP, 최대 3장, 자동 축소 전송)
- **분석**: "이 에러 원인이 뭐 같아?" — 이미지 속 텍스트·에러를 읽고 답합니다
- **이어서 대화**: 분석 결과는 대화에 기억됩니다 — "아까 그 스크린샷 기준으로 재현 단계 정리해줘"
- **티켓 반영**: "이 화면으로 티켓 만들어줘" — 에러 원문이 티켓 배경에 들어갑니다
- **보관 정책**: 이미지 원본은 서버에 저장되지 않습니다(분석 후 24시간 내 자동 삭제). 새로고침하면 채팅에는 파일명만 남습니다.

## 자주 묻는 질문

| 질문 | 답 |
|---|---|
| 응답이 안 와요 | 잠시 기다렸다가 새로고침. 실패 표시가 뜨면 "다시 시도" |
| "내 티켓"이 안 돼요 | Notion 매핑 필요 — 관리자에게 요청 |
| 계정이 잠겼어요 | 15분 후 자동 해제, 급하면 관리자에게 잠금 해제 요청 |
| 비밀번호를 잊었어요 | 관리자에게 재발급 요청 → 임시 비밀번호로 로그인 → 즉시 변경 |
| 다른 사람 대화가 보이나요 | 아니요 — 대화는 본인만 접근할 수 있습니다 |
