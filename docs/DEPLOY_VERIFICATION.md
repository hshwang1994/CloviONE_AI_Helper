# 배포 게이트와 사람 확인 체크리스트

이번 배포는 **한 번에** 나간다(UI 전면 교체 + 마이그레이션 0022~0028). 롤백 단위가 크다는
뜻이라, 되돌릴 수 있다는 것을 배포 당일이 아니라 **미리** 증명해 둔다.

이 문서는 두 부분이다.
- **1부 — 기계가 하는 게이트**: 명령 하나로 통과/실패가 갈린다. 하나라도 빨간불이면 배포하지 않는다.
- **2부 — 사람이 해야 하는 확인**: 에이전트는 운영에 로그인할 수 없다. 헤드리스 스크린샷만으로
  "됐다"고 하지 않기 위해, 사람이 직접 눌러 봐야 하는 것만 모았다.

---

## 1부 — 기계가 하는 게이트

순서대로 돌린다. 각 줄의 **성공 신호**가 나와야 다음으로 간다.

| # | 명령 | 성공 신호 |
|---|---|---|
| 1 | `.venv/Scripts/python.exe -m pytest -q` | 실패 0 |
| 2 | `cd frontend && npm test` | 실패 0 |
| 3 | `cd frontend && npm run build` | `✓ built` |
| 4 | `bash scripts/static_checks.sh` | `STATIC_CHECKS_OK` |
| 5 | `bash scripts/check_bundle_size.sh` | `BUNDLE_BUDGET_OK` |
| 6 | `STEPS=7 bash scripts/migration_rehearsal.sh` | `REHEARSAL_OK` |
| 7 | `.venv/Scripts/python.exe scripts/restore_rehearsal.py` | `RESTORE_REHEARSAL_OK` |
| 8 | `.venv/Scripts/python.exe -m scripts.ui_qa.run --label release --fail-on ...` | `치명 검사 실패 없음` |

### 게이트마다 무엇을 지키는가

**4번 `static_checks.sh`** 안에는 실제로 터진 사고에서 나온 검사가 들어 있다.
- *추적 파일이 미추적 모듈을 import* — 워킹트리에서는 전부 통과하고 **fresh clone 에서만**
  죽는다. 즉 배포 서버에서 처음 발견된다. 판정은 인덱스가 아니라 **HEAD** 기준이다
  (staged 지만 미커밋인 파일을 '있다'고 세면 검사가 헛돈다 — 그렇게 두 번 새 나갔다).
- *정의 없는 CSS 변수를 fallback 없이 참조* — 그 선언 하나가 아니라 **선언 전체**가 무효가
  된다. 로그인 오류 애니메이션이 이것 때문에 시선 위치를 통째로 잃고 있었다.
- *Notion 구현 모듈을 저장소 seam 밖에서 import* — 티켓 소스를 바꿔 끼울 수 없게 만든다.

**6번 마이그레이션 리허설**은 up→down→up 왕복 후 **스키마와 행 수를 앞뒤로 비교**한다.
SQLite 의 `batch_alter_table` 다운그레이드는 테이블을 **재생성**하므로 컬럼 순서·기본값·
인덱스가 조용히 달라질 수 있다. 왕복이 성공하는 것만으로는 부족하다.

**7번 복구 리허설**은 백업을 되돌린 뒤 **앱을 띄워 ORM 테이블을 전수 조회**한다.
파일 검사만으로는 부족하다는 것을 실제로 확인했다 — 옛 스키마 백업에서 체크섬·
`integrity_check`·행 수·`/healthz` 200 이 **전부 통과**하는데 테이블 8개가 죽어 있었다.

> **8번 전에 서버를 반드시 새로 띄운다.** 오래 떠 있는 uvicorn 은 옛 모듈을 물고 있다.
> 실제로 이것 때문에 응답에서 필드 하나가 통째로 빠진 채로 캡처를 찍었다. 서버를
> 재시작하니 바로 나왔다. **시각 검증 결과는 서버를 새로 띄운 뒤의 것만 유효하다.**

### 배포 순서 (뒤집으면 깨진다)

1. 백엔드 먼저 (CSP·마이그레이션·라우터)
2. 그다음 프런트 번들

> 옛 번들은 새 CSP 에서 잘 돌지만, **새 번들은 옛 CSP 에서 안 돈다**. MUI 가 런타임에
> `style=""` 를 쓰기 때문이다. 순서를 뒤집으면 화면이 통째로 깨진 상태가 생긴다.

### 알려진 함정

- `py_compile` 게이트가 남기는 `__pycache__` 를 배포 전에 지운다.
- nginx 는 `10.100.64.71:443` 을 본다 — `127.0.0.1` 이 아니다.
- sudo 비밀번호는 stdin 으로 넘긴다.

### 실패 시 롤백

서비스 중지 → DB 백업 복원 → 직전 번들 복구 → 헬스 재확인.
**티켓 읽기 경로만 문제라면** `TICKET_SOURCE=notion` 으로 되돌리고 재시작(5초)한다 —
전체 롤백이 필요 없다.

## 2부 — 사람이 해야 하는 확인

에이전트가 못 하는 것만 남겼다. 각 항목은 **무엇을 보면 통과인지**를 함께 적었다.

### A. 4K 디스플레이 (가장 중요 — 지원 해상도가 4K까지다)

실제 4K 패널에서 **배율 100% 와 150% 둘 다** 본다. 둘은 서로 다른 CSS 폭이다
(100% = 3840px, 150% = 2560px). 윈도우 4K 기본값이 150% 라 실사용자 대부분이 그쪽이다.

- [ ] **100%(3840px)** — 좌우가 비어 보이지 않는가. 표가 열을 더 보여주는가. 글자가 작지 않은가.
- [ ] **150%(2560px)** — 같은 화면이 어색하게 늘어지지 않는가.
- [ ] 두 배율에서 **홈 / 내 티켓 / 팀 티켓 / 스프린트 / 채팅방 / 문서 / 관리자 대시보드** 를 훑는다.
- [ ] 가로 스크롤바가 생기는 화면이 하나라도 있으면 실패다.

### B. 로그인 화면 (공들인 부분 — 동작이 하나라도 달라지면 실패)

- [ ] 마우스를 움직이면 **대기 상태에서만** 눈이 따라온다.
- [ ] 이메일 칸을 누르면 시선이 오른쪽으로, **비밀번호 칸을 누르면 시선을 돌린다**(안 보는 연출).
- [ ] 일부러 틀린 비밀번호 → 눈이 **시선 위치에서** 좌우로 흔들린다(시작할 때 튀면 실패).
- [ ] 로그인 성공 → 눈이 커지며 밝아진다.
- [ ] Caps Lock 을 켜고 비밀번호 칸에 입력 → 경고가 뜬다.
- [ ] 탭을 다른 창으로 옮겼다 돌아오면 애니메이션이 멈췄다 다시 돈다.
- [ ] **자바스크립트를 끄고** 로그인 → 그래도 동작하고, 주소창에 비밀번호가 남지 않는다.
- [ ] 잠긴 계정 / 비활성 계정 / 보관된 계정 / 세션 만료 — 안내 문구가 각각 다르게 나온다.

### C. 처음 한 번만 겪는 흐름

- [ ] 새 계정으로 첫 로그인 → **비밀번호 강제 변경** 화면이 나오고, 바꾼 뒤 정상 진입한다.
- [ ] 다크 모드로 바꾸고 **로그아웃 → 재로그인** → 다크 모드가 유지된다.

### D. 쓰기 동작 (읽기는 자동 검사가 봤다. 쓰기는 사람이 봐야 한다)

- [ ] 티켓 생성 → **Notion 에 실제로 만들어졌는지 Notion 에서 확인**한다.
- [ ] 티켓 수정(상태·담당자) → 화면에 즉시 반영되고 Notion 에도 반영된다.
- [ ] 티켓 본문 편집 → 저장 후 새로고침해도 남아 있다.
- [ ] 관리자 화면군마다 쓰기 한 번씩: 사용자 / 부서 / 설정 / 승인 / 공지.
- [ ] 문서를 휴지통에 넣고 **복원**한다.

### E. 채팅

- [ ] 이미지를 **Ctrl+V 로 붙여넣기** → 말풍선 안에 보인다.
- [ ] 그 이미지 주소를 복사해 **다른 계정(그 방 비멤버)** 으로 열어 본다 → 열리면 안 된다.
- [ ] 네트워크를 끊고 전송 → 실패가 보이고, 다시 연결 후 재시도가 된다.
- [ ] 안 읽은 메시지가 있으면 **사이드바 '채팅방' 옆에 숫자 배지**가 뜬다.
- [ ] 그룹방을 방장 계정으로 파한다. **1:1 대화는 파하기가 안 되고 '숨김'만 된다** — 숨긴 뒤
      상대가 메시지를 보내면 다시 나타난다.

### F. 알림

- [ ] 채팅 초대 알림을 누르면 **그 방으로 이동**한다.
- [ ] 알림 종류별로 눌러 보고, 엉뚱한 곳으로 가는 것이 없는지 본다.

### G. 키보드·접근성

- [ ] `Ctrl+K` 로 명령 팔레트가 열리고 `Esc` 로 닫힌다.
- [ ] 페이지 로드 후 **첫 Tab** 이 '본문 바로가기'로 간다.
- [ ] OS 에서 '동작 줄이기'를 켠 사용자로 한 번 본다 → 애니메이션이 줄어든다.

## 판정

위 두 부분이 **전부** 통과해야 배포한다. 하나라도 미확인이면 미확인이라고 적는다 —
"됐을 겁니다"로 바꾸지 않는다. 부분 통과는 숫자로 쓴다("12개 중 9개 확인, 3개 미확인").
