# 지금 배포하기 — 남은 한 줄

2026-08-04 UI 전면 정렬 + 제품화 작업의 **기계 게이트 8개가 전부 통과**했고, 번들은 이미
운영 서버에 올라가 무결성까지 검증된 상태다. 남은 것은 **root 권한이 필요한 한 줄**뿐이다.

에이전트 실행 환경이 sudo 비밀번호 전달을 차단한다(지난 세션에도 같은 지점에서 막혔다).
우회하지 않고 여기 적어 둔다.

---

## 1. 지금 서버 상태 (확인함)

| 항목 | 상태 |
|---|---|
| `~/deploy/clovirone-web-assistant-bundle.tar.gz` | 올라감 (50,031,727 바이트) |
| `~/deploy/stage-new/` | 풀림, `sha256sum -c` **855개 파일 전부 일치** |
| 마이그레이션 0034 / 0035 / 0036 | 스테이징에 포함 |
| 프런트 새 번들 | 스테이징에 포함 |
| 운영 서비스 | `active` (아직 **옛 코드**로 동작 중) |

운영은 아직 마이그레이션 0033, 옛 자산 해시, 제품명 `ClovirONE 업무 도우미` 다.

---

## 2. 실행할 한 줄

```bash
ssh -t cloviradmin@10.100.64.71 'sudo STAGE=$HOME/deploy/stage-new $HOME/deploy/stage-new/app-src/scripts/upgrade-clovirone-web-assistant.sh'
```

`-t` 라 sudo 가 비밀번호를 **직접 물어본다**. 비밀번호는 명령행·파일·환경변수·git 어디에도
남지 않는다(저장소 불변 규칙 §4).

이 스크립트가 하는 일(순서 그대로):
1. **백업 먼저** — 되돌릴 지점을 만든다.
2. 워커 → 앱 순으로 정지(진행 중인 작업을 흘려보낸다).
3. 멱등 installer 재실행 — 소스 교체, 의존성 설치, **`alembic upgrade head`**,
   유닛 파일, **nginx vhost 교체(새 업로드 location 3개 포함)**, 기동.
4. 끝에 `UPGRADE_OK`.

> 순서를 바꾸지 않는다. 백엔드(CSP·마이그레이션·라우터)가 먼저고 프런트 번들이 그다음인데,
> 이 스크립트가 그 순서로 한 번에 한다. 옛 번들은 새 CSP 에서 돌지만 **새 번들은 옛 CSP 에서
> 안 돈다**(MUI 가 런타임에 `style=""` 를 쓴다).

---

## 3. 끝나면 바로

```bash
bash scripts/verify_deploy.sh
```

`DEPLOY_VERIFY_OK` 가 나와야 한다. 지금 돌리면 **5건 실패**가 나온다 — 그게 정상이고,
배포 뒤에 전부 OK 로 바뀌는지가 확인이다. 무엇을 보는가:

| 검사 | 배포 전 | 배포 후 기대 |
|---|---|---|
| `/healthz` `/readyz` | 200 | 200 |
| 로그인 화면 제품명 | 옛 이름 | `ClovirAssist` |
| 정적 자산 해시 | 옛 번들 | 새 번들 |
| `GET /api/admin/organizations` | **404** | **401** (라우터가 실렸고 인증벽만 막는다) |
| `GET /api/tickets/attachments/none` | **404** | **401** |
| CSP | 옛 정책 | `script-src 'self' 'unsafe-inline' 'unsafe-eval' https:` |

404 가 401 로 바뀌는지를 보는 이유: 200 을 기대하면 인증이 필요한 라우트라 확인이 안 되고,
404 는 "그 코드가 아예 안 올라갔다"는 뜻이다. 이 둘의 차이가 곧 배포 성공 여부다.

---

## 4. 안 되면 되돌리기

```bash
ssh -t cloviradmin@10.100.64.71 'sudo /opt/clovirone-web-assistant/scripts/rollback-clovirone-web-assistant.sh <BACKUP_DIR>'
```

`<BACKUP_DIR>` 은 2번 스크립트가 1단계에서 만든 백업 경로다(출력에 나온다).
**티켓 읽기 경로만 이상하면** 전체 롤백 대신 `TICKET_SOURCE=notion` 으로 되돌리고
재시작(5초)하면 된다.
