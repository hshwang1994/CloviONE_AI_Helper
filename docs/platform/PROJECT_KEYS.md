## 왜 사람이 정했는가

**Key 소유는 영구다.** 한 번 쓰인 이름은 `retired` 가 될 뿐 다른 프로젝트로 넘어가지
않는다 — 그것이 `<KEY>-<SEQ>` 가 전역에서 충돌하지 않는 유일한 근거다(D-196).
되돌릴 수 없는 이름을 기계가 짓게 두지 않았다(D-197).

`app/work/keys.py::suggest()` 는 초안 후보를 만들 수 있지만 사람이 읽기 어렵다
(브로드컴 → `BRDK`). 아래 표는 **손으로 지은 것**이고, `suggest()` 는 앞으로 새
프로젝트를 만들 때 빈칸을 채워 주는 보조 도구로 남는다.

**재사용 금지** · URL 안전.

프로젝트가 그 이름을 가져가면 새로 발급한 `GIT-142` 가 옛 것과 같은 문자열이 된다.

### 이름은 2026-08-23 에 갈았다. Key 는 안 바꿨다 (S13)

확정 당시(2026-08-22) 소스의 제목에는 `P. `·`M. `·`D. ` 접두사가 붙어 있었고 14번은
`M. 현대모비스 [OKE KVM 윈도우 기능 개` 로 잘려 있었다. 하루 뒤 소스에서 접두사가 전부
사라지고 14번 이름도 완성됐다 — **그 상태로는 20건 전부가 «못 찾음»** 이다(실측 0/21).

앞 판이 그때 할 일을 이미 적어 두었다: 「소스에서 이름을 고치면 그때 이 줄과
`app/work/project_keys.py` 를 함께 고친다.」 그래서 **이름만** 갈았다.

| | |
|---|---|
| **Key 20건** | 한 글자도 안 바꿨다. 소유는 영구다(D-196) |
| **이름** | 지금 소스 실측으로 갈았다. 이름은 Key 를 **처음 붙일 때** 쓰는 손잡이일 뿐이다 — 한 번 붙으면 `projects.code` 가 정본이라 이름이 또 바뀌어도 상관없다 |
| **짝을 무엇으로 확인했나** | 이름이 아니라 **티켓 수**로 20/20. 이름만 보고 「비슷하니까」로 정하면 그것이 U11 이 금지한 임의 배정이다 |
| **옛 이름** | `app/work/project_keys.py::SUPERSEDED_NAMES` 에 그대로 남겼다. 소스가 되돌아가거나 아직 안 따라온 미러도 같은 Key 로 붙는다 |

「티켓」 칸의 수는 **확정 시점(2026-08-22)의 실측**이고 갱신하지 않는다 — 그때 무엇을
보고 정했는지가 이 표의 값이다. 그 뒤 사흘치 작업이 늘어 지금 수는 조금 다르다.

**Key 가 없는 프로젝트가 둘 있다.** `S협회 [빅데이터 포털 구축]`(활성)과
`M. 고려대학교 [NSX-T 구축]`(보관됨)이다. 확정이 20건이므로 **정상이다** — 그 둘의
티켓은 번호를 안 받고 옛 이름(`GIT-n`)으로 계속 열린다.

## 적용 — 지금 무엇이 됐고 무엇이 남았나

| | |
|---|---|
| **확정 기록** | 이 문서 + `app/work/project_keys.py::CONFIRMED`. 시험이 둘을 맞물어 둔다 |
| **적용 함수** | `app/work/project_keys.py::apply_confirmed(db)`. 이름으로 잇고, **못 찾으면 배정하지 않는다.** 재실행해도 같은 결과다 |
| **지금 적용된 프로젝트** | **0건** — PostgreSQL 의 `projects` 가 비어 있다. 운영 데이터는 아직 SQLite 에 있고 적재는 S13 이다 |
| **S13 이 할 일** | 프로젝트를 적재한 **직후** `apply_confirmed(db)` → `numbering.seed_counters(db)` → 재채번. 순서가 뒤바뀌면 번호가 겹친다 |

적용 결과는 다섯 갈래로 보고한다 — `applied` · `already` · `not_found` · `ambiguous` ·
`other_key`. 「했다/안 했다」 둘로 뭉치면 **왜 안 했는지**를 다시 조사해야 한다.

## 확정 전이었다면 막혔을 것 — 지금은 아니다

Key 가 없어도 제품은 돈다. Key 없는 프로젝트의 티켓은 번호를 안 받고 옛 이름(`GIT-n`)으로
불릴 뿐이다(`app/work/service.py::number_if_possible`). 확정이 풀어 준 것은 **S13 의
재채번** 하나다.
