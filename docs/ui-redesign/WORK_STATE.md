## NOW

**A 가 답한 것은 하나다 — 화면들이 같은 말을 쓰는가.** 나머지 여섯 묶음이 그 위에 선다.

- **Status 와 Signal 을 갈랐다** (D-349). Workflow Status 는 여섯이고(`계획 · 진행 중 ·
  검증 · 완료 · 보류 · 취소`) 이슈·차단·지연은 그것과 직교하는 신호다. 운영의 `이슈`
  아홉 건은 이름만 바꾸지 않고 **실데이터를 본 뒤** 옮겼다 — 아홉 전부 일이 시작된 흔적이
  없어서 업무 위치는 `계획` 로, 「이슈로 표시했다」는 사실은 `issue_flag` 로 나눠 적었고,
  옮긴 사실 자체는 티켓 타임라인에 시스템 활동으로 남는다.
- **표의 정렬 계약을 바꿨다** — 머리글 이름은 언제나 가운데(`1fr auto 1fr` 격자라 조작기가
  이름의 중심을 안 민다), 몸통은 값의 의미대로(읽는 것은 왼쪽, 나머지는 가운데).
  수치 열이 우정렬에서 가운데로 옮겼고 자릿수 고정은 남았다. QA 프로브 둘도 새 계약으로
  다시 적었다 — 옛 판정을 두면 제품이 아니라 검사가 옛 계약을 들고 있게 된다.
- **곁열 없는 상세의 왼쪽 쏠림을 뿌리에서 고쳤다** — 겹쳐 걸린 상한 셋(72ch / 68rem /
  본문 영역)을 하나로 줄이고 그 열을 가운데 세웠다(`ui/DetailLayout.jsx`).
- **목록 상태가 살아남는다** — 「목록」이 경로가 아니라 **주소**로 돌아가고 스크롤도
  기억한다(`lib/listReturn.js`). 화면별 전역변수를 쓰지 않는다.
- **Avatar 가 생겼다** (D-350) — 사진이 없는 사람도 자기 그림을 갖는다. 그림은
  **DiceBear 를 브라우저 안에서 돌려** 만든다: 외부 API 도 CDN 도 안 쓰므로 인터넷이 없는
  망에서도 그려지고, 설치 시점에 npm 도 필요 없다(커밋된 번들 안에 있다). 스타일 다섯은
  전부 CC0 1.0 이고 각 스타일에 변형 1,000 이라 조합이 5,000 이다. 그림은 지연 청크로
  받는다 — 진입 번들에 넣으면 초기 예산 280KB 가 두 배가 된다.
  사진은 **서버가 다시 그린다**: EXIF 회전을 펴고 사람이 고른 자리를 자른 뒤 픽셀만으로
  WebP 를 쓴다 — 원본 메타데이터는 한 바이트도 안 따라온다.
- Callout 이 `아이콘 · 제목 · 본문 · 동작` 구조를 갖고, `PageHeader` 가 짧은 설명 자리를
  소유한다(화면 여섯이 각자 다른 바닥 여백을 적고 있었다).
